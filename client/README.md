# CodeMentor client

The React and Vite frontend for CodeMentor is part of the npm workspace.

For project features, architecture, setup, environment variables, and development commands, see the [root README](../README.md).

From the repository root, start the frontend with:

```sh
npm run dev -w client
```

The Vite development server proxies `/api` requests to the backend at `http://localhost:5000`.
